# Bierpong-Tracker

Trefferquoten-Tracker für die Turniervorbereitung. Ein iPhone über den Bechern erkennt Treffer im Browser, ein zweites Gerät zeigt Dashboard und Auswertungen.

- Projektplan: [`tracker-plan.md`](tracker-plan.md)
- Trainingsplan: [`bierpong-trainingsplan.md`](bierpong-trainingsplan.md)

## Lokal starten

```bash
npm install
cp .env.example .env.local   # DATABASE_URL eintragen
npm run dev
```
