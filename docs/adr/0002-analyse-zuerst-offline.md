# Wurfanalyse zuerst offline an Aufnahmen, live als Ziel

Die Erkennung der Deckenkamera wurde live am Tisch eingestellt: raten, ausprobieren, wieder raten. Jede Änderung traf auf eine andere Szene, dadurch war nichts vergleichbar. Die Wurfanalyse wird deshalb zuerst gegen **Aufnahmen** entwickelt — dieselben Videos, dieselben Würfe, jede Änderung messbar gegen dieselbe Messlatte.

## Konsequenzen

- Der Erkennungskern wird so geschnitten, dass er sowohl aus einem Skript am PC als auch später im Browser live aufgerufen werden kann. Beide Wege teilen sich denselben Code.
- Aufnahmen entstehen mit dem Gerät, das später auch live filmt. Material von einer besseren Kamera würde eine Genauigkeit vortäuschen, die im Betrieb nicht existiert.
- Videos werden über Dropbox ausgetauscht und liegen nicht im Repo.
